The MIT License in this repository applies to source code only. It does not
apply to art, 3D models, audio, music, fonts, logos, or other media under
`public/`.

## Current provenance

| Assets | Location | Recorded production source | Reuse status |
| --- | --- | --- | --- |
| UI art, character art, logos, icons, and sprites | `public/ui/`, `public/sprites/`, favicon files | Created for this project, with Nano Banana used during image iteration | No separate reuse license granted |
| 3D models and animations | `public/models/` | Project-integrated; individual generation/source records are not yet documented | Do not reuse until provenance is verified |
| Voices and sound effects | `public/audio/` excluding music | Created or selected for this project, with ElevenLabs used during production | No separate reuse license granted |
| Music | `public/audio/music/` | Created or selected for this project, with Gemini-assisted production | No separate reuse license granted |
| Web fonts | Loaded from Google Fonts at runtime | Black Ops One, Quantico, and Special Elite via Google Fonts | Governed by their respective upstream licenses |

“AI-assisted” describes the recorded production workflow; it is not a license
grant and does not by itself establish copyright ownership. Tool names are
provided for transparency and do not imply endorsement.

## Reusing this project

You may use, modify, and distribute the source code under the MIT License. To
redistribute a build or fork containing files from `public/`, obtain permission
from the relevant rights holder or replace those assets with files you are
licensed to use.

Before granting a reusable license for any asset group, record at minimum:

- the original creator or source URL;
- the generation or purchase date;
- the applicable license or service terms; and
- any required attribution text.

If you own an asset in this repository and believe its attribution or reuse
status is incorrect, open an issue with the file path and supporting source.
